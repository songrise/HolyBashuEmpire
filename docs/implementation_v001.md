# 神圣巴蜀帝国 v0.01 实现与试玩说明

当前包是独立加载的玩法原型，适配本机 EU5 1.4.0。新建 1337 年游戏使用三十六个府州诸侯国，分属七圈，共一百六十四个地块。欧洲神罗继续存在。

## 已实现内容

| 系统 | v0.01 行为 |
|---|---|
| 国家与地图 | 36 国，每国 3–10 地块，36 位架空统治者；文化、宗教及原人口按地图保留 |
| 帝国与选侯 | 独立帝国组织、7 个圈级组织；开局每圈一席、共七席；原生投票，严格多数选帝 |
| 天府待遇 | 合资格诸侯域内地块粮食产出 +10%、本地建造速度 +10%；每块地一份，按月维护 |
| 区域隔离 | 组织的宣战规则及参战召集规则禁止跨界战争；允许内部战争与本地叛乱；没有盟约失效年份 |
| 研究 | 64 项决议研究，费用 3/6/10，计时 3/5/8 年；共同知识 8 项，每圈 8 项；地区专精互斥 |
| 阶段任务 | 35 项决议验收，7 圈各 5 项；按 1337/1352/1372/1397/1437 年、先前验收、地区研究及履约储备开放 |
| 续办事业 | 每圈一种组合事业，三年交付、五年续办，获得地区储备及五年临时经营收益 |
| 盐引融资 | 川南盐业专精研究后可借 15 金币，增加 10 盐债；上限 30，年息 1；可还款 |
| 公共资源 | 义气与锅气，范围 0–100；研究、事业和验收增加信用，事件及帝国茶会提供资源取舍 |
| 事件 | 17 个：开局、研究交付、事业交付、账本、茶会、7 圈纠纷、5 次长期转折 |
| 美术 | 原版通用场景插画、基础图案国旗、自制格纹决议 DDS 及 PNG 封面占位 |

研究负责记录知识、解锁事业和阶段验收，并增加共同信用；本版没有将策划中每个研究节点的全部独有效果逐条接入。地区纠纷消耗或补充同一地区储备，与任务争用资源。盐酒圈额外有研究解锁的融资、利息与还款循环。长期事件在 1352、1372、1397、1422、1437 年开放，1457 年后仍可续办公共事业。

任务与地区研究通过“决议”操作。七圈在本版是七个独立协作组织，各国同时属于帝国与地区圈；尚无专用嵌套层级界面。商邦、山门及共治国的专属政体、36 府州各自完整事件变体、复杂合同、完整帝国改革和规划中的 110 主线任务、79 核心事件属于后续版本目标。

开局为七圈各一选侯；当前自动补位允许其他存活成员，不保证被兼并后仍保持每圈一席。事件强制宣战、特殊脚本战争及本地国家迁都域外的边界行为还需专项试玩。

## 加载与安装

发行包解压后，第一层有 `holy_bashu_empire/`、`Install-Mod.ps1`、`Launch-Mod.ps1` 和说明文件。模组目录内包含 `.metadata/metadata.json`、`loading_screen/`、`main_menu/`、`in_game/`，不依赖制作时的工作目录。

可运行安装器并从游戏模组管理器启用；或运行启动器直接加载。启动器默认创建专属 `文档/Paradox Interactive/EU5 Holy Bashu Empire` 用户目录，写入一个只启用本模组的播放集。这样新存档和原版游戏用户目录分开保存。传入自定义 `-UserDataPath` 时，启动器会备份原播放集并将专属播放集设为当前活动集。

在 PowerShell 中运行：

```powershell
./Launch-Mod.ps1
# 自定义安装路径或查看调试日志：
./Launch-Mod.ps1 -GameDirectory 'D:\SteamLibrary\steamapps\common\Europa Universalis V' -DebugMode
```

请先启动 Steam，再进入游戏。选 1337 年，从巴蜀地图或新增推荐国家选择诸侯。选成都可测试帝国茶会，选叙州可走盐引融资。其他覆盖 1337 国家所有权或固定消息类型表的模组会冲突，首轮单独加载本包。

## 首轮试玩检查

1. 查看七圈及七席成员；选府州小国核对首府和地块；确认“天府之国”两项修正各为 +10%。
2. 开始本圈第一项研究，确认付费、研究计时、到期交付以及续办事业入口。
3. 续办公共事业，核对地区储备、义气、临时经营收益与冷却；用储备完成一次阶段验收。
4. 研究专精后确认另一支被封锁；叙州测试盐引贷款、年度利息及还款。
5. 确认域外宣战及参战召集被阻止，而内部诸侯仍可宣战；测试继承、兼并及选侯补位。
6. 保存并重载；继续到 1352/1372/1397/1422/1437 年检查阶段事件和验收，再确认 1457 年后事业仍可继续。
