# 0.3.2 热补丁：红巾局势行动对 HBE 的克制

汉、吴等十四个原版红巾局势衍生势力，以及原版标记识别的动态军阀和改朝换代势力，对现存 HBE 成员的「争夺地区霸权」「要求吞并」正向行动评分保留 45%。零分和负分保留原值；HBE 接受此类直接吞并要求额外减 100 点。普通扩张规则仍保留原有乘数，45% 是两项专用行动的评分倍率，不能解释为宣战概率。

攻击者须为 HBE 外部势力。行动对非 HBE 目标、HBE 内部行动和普通外国的计算不受这项热补丁影响。没有增加年份限制或额外停战。原版行动的条件、效果、原有接受理由等都保留。
