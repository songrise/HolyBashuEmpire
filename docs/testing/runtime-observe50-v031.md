# 0.3.1 发布前平衡与 50 年测试

一次自然 AI 模拟完成 1337.4–1387.4，11 个检查点、同一存档，无科技、金币、建筑或军队注入。7 项运行断言通过；没有 HBE 非兼容类引擎诊断。原版/DLC 错误与旧兼容定义警告单列，未将整个日志称为无错误。

本次模拟在最后的小幅内部 AI 调整之前完成。最终发布另做三个月引擎加载与脉冲检查，以及内部目标范围/权重静态检查；未将它冒充调整后的第二次 50 年对照实验。

## 诸侯与领土

36 家最终剩 11 家。25 家消失国家的开局领土中，19 家全归现存 HBE 成员，5 家全归外部，1 家内外分割；这是最终所有权分析，不是每次吞并原因的还原。原始164地块中127仍归HBE，37在外部，其中CHI29、两个省级新国家各4。最大圈内诸侯占原始领土45块。

降低内部扩张权重：同派/一般目标 1.05 → 0.95，异派 1.08 → 0.97；额外评分 +3 → +2。只匹配同属HBE的相邻诸侯。外部慎战、全局进取修正、盟约、停战与原版宣战理由不变。权重不是直接宣战概率。

## 经营与平衡

义气第15年均值97.3，终点99.91；役负终点3.45。说明义气60资格门槛后期约束偏弱，高役负惩罚少触发。和平年役负降低3，须不处于工程突击冷却；地方事业可带来不同役负，部分地区机构再给予减负。不能将和平恢复解释成所有政策每年都无条件减负。此处记录为后续经济设计问题，本次未追加未要求的统一削弱。

存续国家金币中位数509.84，有明显积累，但兼并导致存续样本规模增大；仅凭存款不能证明每个小国收入失衡。第10年中位数3.57，第15年56.43；中期曾有负金国家。

已控制可比较单项全局生产/粮食科技奖励：生产上限5%，粮食10%，不超过选定原版常见参照的2倍。不同科技叠加后的总额不是按此单项上限截断。临时全局产出使用同类较强者替换，避免重复堆叠；原先0.7奖励调整未重复执行。费用及部分收入采用原版经济基础公式，非统一固定10/20金币。

四类商品参考价格为对应普通商品的1.25–2倍，不将参考价当作实际市场价。9种特色兵实际编制500人，维护实物需求为对应原版90%；两类升级单位战力系数1.20、1.15。13种民用机构每国每类最多3座、每处一级，取消民用征募效果。

## 产业和内容的实际表现

终点蜀绣2.71081、井盐10.60648、边茶0.86391实际生产，且存在需求与实际价格记录；蜀纸仍0，需继续观察AI的时代科技、生产选择与启动。51级特色建筑、49座有雇员，特色军团1队。单局样本不足以证明兵种实战强弱或招募概率。

自然AI没有签客籍议约，也未采用两项新增政府改革。客籍玩家路线已用实际决议和三类机构做针对性验证，7地区11个基础配方注册齐全；只授予基础使用权，不复制外国整套科技。移民1345起，10章约49年，最后章节名义1394，本次1387终点尚未覆盖完整移民结局。
