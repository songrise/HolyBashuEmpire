# 0.3.1 本地深度数值核查

核查日期：2026-10-14。仅本地应用，未上传 Steam、未 push Git 远端。405 个可见事件及 1272 个选项保留。

## 原版尺度与本次调整

直接读取当前安装的原版 `scaled_gold.txt`、科技、修正类型与政府改革定义，未使用参考价格冒充实际市场成交价。

| 项目 | 原版可比样本 | HBE 调整 |
|---|---|---|
| 科技全局生产效率 | 34 个可解析正数样本，中位数 2.5%，最高 5% | 8% → 4%；12% → 5% |
| 科技全局粮食 | 48 个样本，中位数 5%，最高 12.5% | 12% → 8%；16%／20% → 10% |
| 临时全局生产／粮食 | 按同类科技常用 2.5%／5% 尺度设保守上限 | 单项最多 5%／10%；164 种临时安排的这两类效果分别共用一个槽，取较强值，不叠加 |
| 地方事业、任务等行政支出 | 原版经济规模公式 | 43 个有效付费决议动态化；雇工额外工资仍单独计算，门槛与实际扣款一致 |
| 事件收益 | 同一原版经济规模公式 | 77 个普通金币收入动态化，借款偿还与托管资金仍按原始账面金额 |
| 会盟成功与领先派奖励 | 收益补足此前未覆盖的削弱 | 成功：动态金币、2 威望、4 义气，生产至多 5%、粮食 8%；共建派建设 14%，兴业派商人容量 18%、文化影响力 14% |
| 会盟出资 | 收入比例费用 | 按月税贸收入的35%计算，最高出资 6 → 64 金币，最低 2 金币 |
| 升级特色兵战力 | 原版模板战力为累加继承 | 两个升级兵种实际战力从错误的 2.20／2.15 改为 1.20／1.15；500 人和维护需求降低 10% 保留 |

生产与粮食的 2 倍上限针对单项可比奖励，并对 HBE 同类临时安排限制合计；原版式永久科技仍可累计，没有把整个国家全部来源的总加成硬截断为 5%／10%。

经济规模基础值为 `1 + 0.2 × 首都财富 + 0.05 × 国家经济基础`。行政费用按原先等级分档缩放，普通收入按原金额除以四设置尺度，并沿用原版式下限、上限。没有把所有事件统一设成 10／20 金币。

## 两项 HBE 共有政府改革

两项均为次要改革，所有 HBE 成员均有资格；通过原版改革槽与实施规则采用，可以同时采用，不强制在开局添加。基准实施时间 5 年，实际时间受原版修正影响。

| 改革 | 条件 | 收益与代价 |
|---|---|---|
| 府州公议 | 已研究 `hbe_tech_common_1` | 每月控制力 +1%，每月识字率 +0.5%；市民阶层满意度均衡点 +2%，贵族 -2% |
| 山川转运 | 已研究 `hbe_tech_common_2` | 商人容量 +10%，商人维护效率 +5%；税收效率 -2% |

已有本地图标沿用，补充中英文名称与叙事说明；离开 HBE 后相关国家修正不再有效。

## 验证

- 静态检查通过 14,185 项，大部分为文本键唯一性，另检查脚本结构、奖励上限、持续时间、费用门槛、兵力继承与改革名称。
- 从已提交基线重新应用完整补丁链，639 个运行文件与已测候选逐文件哈希一致；构建清单单独刷新。
- 一个月隔离原生实机测试：15 个断言全部通过。示例行政费用 7.71624，实际扣款 7.71624；动态收入 3.95947，实际到账 3.95947。
- 连续给予生产 3%、5%、2%，粮食 4%、8%、6%：次日实际净增加 5%／8%。存档中每类只有一个修正，期限均为 1337.7.5，较弱安排没有覆盖或缩短较强安排，也没有累加期限。
- 两项改革已登记并进入实施；外部国家排除、费用分档也通过断言。
- 新增功能没有引擎错误。5 条测试专用变量未被脚本读取的登记提示，以及原版／旧兼容定义诊断单列，不视为运行脚本错误。

首轮短测发现持续时间同时写入零年、正数月、零日会使效果立即到期；改为仅提交一个持续时间字段后，本轮通过。首轮夹具还误删两处变量名称，已修正夹具，保留原始失败证据。

该测试人为提供测试金币、科技和建筑，用于功能核对，不替代自然 AI 的 20／25 年观察。它不能证明蜀绣、纸业和特色兵已自然启动。原有长期观察结论保留。

四种特色货物已经接入全球原版人口需求，没有限制为 HBE 或特定文化；外部汉文化地区也能形成需求。实际需求取决于人口发展、财富、供给等条件，不能仅从配置推断成交量。参考价格与生产方式投入产出只用于静态比较，不作为实现利润。
