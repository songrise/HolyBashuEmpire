# 外交倾向与朝贡资格：源码候选（2026-10-19）

按用户最终意见保留红巾正向战争及要求吞并行动评分 30%，一般对 HBE 扩张倍率 0.65、拒绝直接吞并 -100 均不变。没有改为 40%。

原版红巾“争夺地区霸权”CB 针对 HBE 时，对 AI 红巾主攻国的额外战争热情减 0.05。使用原版 additional_war_enthusiasm_attacker 接口，只影响外部红巾主攻、HBE 主守的战争；玩家红巾、次要参战盟友、非 HBE 目标及红巾对元的 CB 保持原样。此值用于原版议和判断，不是战斗加成或战斗胜利分数，不强制白和。其他普通 CB 不在本次调整范围内。

内部相邻诸侯扩张评分：基础倍率 0.95→0.85，异派额外倍率 0.02→0.01（总倍率 0.97→0.86），固定加分 2→1。模组额外推荐内部目标的休养期：一般 12→15 年，好战/扩张性格 8→10 年；邻府候选分由税基×4+4 改为税基×3+2。AI“府州竞逐”的进取加成为 5%→2%，战争间隔从 -3 月改为 +3 月。这些是 AI 目标评分和倾向，未修改玩家兼并规则、外交整合速度或战争合法性；不会阻止所有提前发生的原版内部战争。

朝贡使用用户批准的通用方案：给 hbe_empire 的所有成员增加原版 allow_tributary_subject=yes 组织修正。没有霍尔巴、成都或其他国号特例，没有改霍尔巴政体，没有覆盖原版 tributary 定义。此权限允许成员接纳不符合“部落/游牧目标”旧条件的朝贡国，但原版国阶、关系接受度、贡赋、外交自主、退出及禁止直接整合等规则继续保留。四条批准的开局 dependency 不变；梁及其属国不变。

修复针对新局的朝贡资格回退原因。旧档中已经被引擎改成普通附庸的关系不会被事件自动转换。本轮只做静态检查和重复生成检查，不启动 EU5、不做长期测试、不安装或发布。实际主菜单预设和长期行为仍待后续实机验证。

实现依据为当前原版 casus_belli/readme.txt 的战争热情脚本接口、international_organizations 的成员 modifier 接口，以及 tributary.txt 对 allow_tributary_subject 的原生判断。
