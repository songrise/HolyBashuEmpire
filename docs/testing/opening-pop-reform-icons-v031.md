# 开局停战、人口、改革与图标修复

开局停战只持续1337.4.1–1338.4.1。当前引擎的期限字段和开局停战设置仍保留默认五年，故补充仅针对初始36家、630对关系的显式到期处理与期限提示；没有修改全局TRUCE_YEARS。撕毁后的新关系通过双方标记豁免，避免到期事件删除后来签订的停战。
