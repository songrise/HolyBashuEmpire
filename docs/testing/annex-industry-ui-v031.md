# 0.3.1 整国吞并产业继承与可成立列表修复

仅原版 `on_annexed` 完整吞并结束回调授予资格。单独割地、占领、购买一处土地、开局或每月领土扫描均不授予。本规则从安装后的完整吞并开始生效，不从当前领土反推过去是否整国吞并。

吞并者继承被吞并国原属圈，以及其已经正式取得的客籍/产业继承资格对应的基础民用产业：7份自动凭据，共14类地区建筑、11个基础/普通生产方式。军事、外交等完整吞并均支持；外国吞并者也可继承。没有金币/义气费用，无须先研究匠人互访。不会自动赠送特色单位、高级生产方法或地区科技的数值加成。建筑仍限原圈地理范围，原有每国三座与每处一级等限制保留。

正式客籍议约仍提供原本的军制与合作事务资格。既有工坊保留并可沿用生产方式；实际生产继续受雇佣、原料和市场影响。

四川、重庆、巴蜀帝国新增原版 `formable_countries` 登记，分别为 HQS_f、HQC_f、HQB_f。因此会进入国家内容的“可成立”页，而非只有“议议”中的决议。保持原来的领土门槛与关键城市要求，补齐中英文列表名称，并将三个成立后标签补入已有国家专属决议注册。原国家决议成立入口继续保留。
