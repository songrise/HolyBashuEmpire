# 0.3.1 成立国家、兵种与科技补丁

三项国家决议向任何拥有对应领土的国家开放，无文化与年份门槛。须独立、和平，直属拥有并控制核心地块，附庸不计入。

|国号|核心地区|直属控制门槛|必须持有|
|---|---|---|---|
|四川|HBE原始疆域除重庆川东圈，共133处|90处，67%|成都、宜宾、阆中、严道|
|重庆|重庆川东圈，共31处|21处，67%|巴县、涪州、万州|
|巴蜀帝国|HBE原始疆域，共164处|148处，90%|成都、巴县、宜宾、阆中、严道、建昌、遂宁|

成立通过原版国名、形容词、旗帜、地图色与国家等级效果实现。四川/重庆至少为王国，巴蜀至少为帝国。保留原始内部标签、地区资格、成员身份、人物、科技和议约。四川/重庆为两条区域路线，成立区域国家后仍可成立巴蜀帝国；没有额外永久经济或战斗加成。

9类特色兵均保持有效500人及原有九折维护配方，取消全部自定义移速惩罚。弩手强化杀伤，护运兵强化侧翼和士气，江防兵强化抗线和河流战斗，关隘兵强化减损和山地战斗，义仓团练降低补给和粮食需求，茶路护骑强化侧翼和移速，联寨山卒强化主动性与山地/丘陵战斗。高级江防/关镇兵保留1.20/1.15基础战斗力。

所有87项模组科技登记（80项研究节点及7项客籍资格）均无固定年份条件，时代归属、科技前置、任务和实践条件保留。特色兵另加的1352/1457日期也取消，科技解锁仍需所属时代与实践条件。

纳入此前已完成的修复：一年开局停战按实际到期解除；府州公议月识字率+0.01个百分点并修复改革条件作用域；叙州盐酒BAP选国人口95000；四种特色货物40个修正类型注册产出/需求图标。

## 验证

完整结构检查1166项通过；针对性检查49项通过。隔离两个月实机夹具验证各门槛少一块时不可成立、达到门槛可成立、缺少必需城市不可成立；实际存档确认四川、重庆、巴蜀的名称、旗帜、等级与原始身份延续。新成立/兵种定义无引擎登记或运行错误。既有旧变量与孤立兼容事件警告单列。本次未重新跑50年自然平衡模拟。
