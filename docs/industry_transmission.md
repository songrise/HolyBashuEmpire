# 第二时代产业传习

四项科技把已有产业的基础工艺传入原版建筑。各建筑保留全部原版生产方式和产量，新增一个可关闭的副业槽。四项科技均属于第二时代，费用3，没有独立年份门槛，不提供全局数值加成。锦样分授、井灶合煎和茶引分庄与原版第二时代根科技 `renaissance_development` 相连；槽帘传习直接接在关市驿券 `hbe_tech_northern_shudao_6` 后。

这里的折算使用未受修正的基础配方，不包括特色建筑的高级工序与本地产出修正，也不表示所有建筑的就业或成本相等。副业与原版主工序共享该建筑的就业及供料条件。

四座特色生产机构改为基础上限两座，研究对应传习科技后增加一座至三座，计算已建与在建总数，每处仍限一级。锦户讲习院、井灶公廨和茶马交割场沿用各自第一时代的建筑科技；关市券所仍到第二时代的关市驿券才首次解锁两座，不前移到驿堡联络，槽帘传习为其后续子节点。其他民用机构的三座上限不变。旧存档中已经存在的第三座不强制拆除，但未研究传习科技时不能继续扩建。

四项传习科技同时解锁对应特色机构的高级工艺：锦样分授提供锦坊绣作与蜀纸描样，井灶合煎提供井灶精煎，槽帘传习提供蜀纸精抄，茶引分庄提供边茶压砖与蜀纸包茶。这六项工序不再挂在联渠灌溉、井灶改良、公文分驿或商队互保上；蜀纸描样与蜀纸包茶保留原有额外前置。配方、基础生产和原地区科技数值不变。旧档须研究对应传习科技后才能取得这些高级工艺，不自动补发研究。

## 资格

这四项新增的第二时代传习科技按原生圈专属：成都平原圈只能研究锦样分授，川南盐酒圈只能研究井灶合煎，川北蜀道圈只能研究槽帘传习，川西茶马圈只能研究茶引分庄。其他三圈不会凭HBE成员身份取得这些副产工艺。

科技树显示仅使用本圈的稳定历史国号条件，不依赖开局尚未取得的研究或临时变量。研究另须HBE成员身份、对应原生建筑科技及原版父节点。新科技不会自动授予。

客籍议约与完整吞并仍按原规则取得跨圈基础生产和建筑资格；它们不授予其他圈的这四项专属传习或高级工艺。纸业基础仍于第二时代由关市驿券解锁两座机构，槽帘传习保持其后续子节点。

普通建筑的副业保留原版建造条件和主工序。四种副产配方及六种相关机构高级工艺都检查本圈来源、原生产业科技和对应传习研究；旧档即使错误持有其他圈传习科技，也不能凭该科技启用其他圈进阶生产。蜀纸描样与蜀纸包茶保留原有额外前置。配方数值、费用、建筑上限不变。

## 盐与茶的载体

原版盐场只允许沿海或沙漠。新科技增加一个并列条件：当前所有者具备盐业资格并研究井灶合煎，且地点的实际资源是普通盐。原有沿海／沙漠条件完整保留，其他内陆资源不因此开放盐场。原版盐场的普通盐配方、陶土消耗与建造费用不变。

原版没有对应的普通制茶工坊。集镇继续生产所选的原版乡村手工业货物，额外消耗普通茶加工边茶；普通茶资源产出不变。集镇仍受原版乡村地点条件限制。

## 数值与操作

副业首选项为“不兼营”：不消耗原料、不产出货物，没有免除主工序维护费的字段。只有额外副产配方需要新科技解锁，玩家可逐建筑选择。

按当前商品参考价，副业原料价值占副产货值分别约80%、78%、79.17%、75.56%。这仅用于配方比较；实际价格、工资、就业、供料及国家／地点修正共同决定利润。盐场基础产出规模较小，副业增幅比例会高于城市行会；已通过投入成本压低新增利润，没有再叠加全局奖励。AI保留原版生产方式评估，不脚本强制切换，也不注入商品或补贴金币。
