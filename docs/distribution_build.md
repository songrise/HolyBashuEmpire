# 发布包构建

游戏内容生成与发布包压缩分开。工作树内原始美术和开发产物不因分发压缩而改写。

```powershell
python tools/package_mod.py --source mod/holy_bashu_empire --output work/release-0.4.0 --texconv /path/to/texconv.exe --report work/release-0.4.0-package.json
```

- 输出目录必须不存在，且不能位于源目录内。失败的输出不能发布；使用新的目标目录重试。
- 保留输入的全部文件及相对路径，包括未引用资源。不依据脚本引用猜测删除美术。
- 单层、32位ARGB、未压缩DDS可转为BC3/DXT5；已经压缩的纹理、特殊格式、多级mipmap原样保留。
- 每张候选纹理解码检查尺寸、可见区域RGB平均误差及Alpha平均误差；不满足门槛、压缩失败或不节省空间时保留原文件。阈值沿用既有发行流程：RGB MAE≤6、Alpha MAE≤1.5。
- 图片像素允许有BC3编码的微小有损差异，分辨率与原始来源均保留。脚本、GUI、本地化、元数据及其他非DDS文件逐字节复制。
- `build_manifest.json` 文件仍保留，更新为发布包的文件哈希，并记录原始manifest来源；不会把源文件哈希误当作压缩后哈希。
- 生成文件清单、源/包体积、逐文件转换方式与质量指标；写文件时计算一次哈希，不重复全树检查。

发布调用只上传已完成的包。更新安装包不需要再次设置标题、说明和画廊；发布后回读所有语言页，确认描述未改变、版本与安装包大小一致。
