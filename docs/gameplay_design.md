# 神圣巴蜀帝国玩法策划

> v0.01 已改为七圈、三十六个府州诸侯国，共一百六十四个地块。下文逐地块建国及完整内容数量属于旧案或长期规划；当前实现范围以 `implementation_v001.md` 为准。

本作把四川的各个可拥有地块拆成开局独立的诸侯国，再用选举皇帝、诸侯议会和共同法令把它们连接起来。玩家从一个县城起步，可以经营盐井、茶马和商路，可以拉票当皇帝，也可以把邻居打服。帝国的核心矛盾是：大家都希望有人主持公道，大家又都不愿意被管。

风格确定为神罗与巴蜀梗的架空喜剧。这里的皇帝要请诸侯喝茶，盐商愿意赞助加冕却不愿意交税，公文能在山路上走一年。每个笑点都应落到一次有代价的选择上。袍哥、吃席等元素采用有意架空的时代设定。

这是玩法草案。文中的制度与数值是设计目标，数值需通过后续试玩调整。

内容范围确定为至少一百二十年，暂以 1337 至 1457 年为主轴。地方事业沿起业、成长、利益固化、危机重组和百年改章推进；科技、合同、成员关系与公共责任长期延续。完整安排见[百年经营与地区传承策划](century_campaign.md)。

## 一 开局和玩家目标

### 世界设定

暂以 1337 年为首版开局。架空设定中，大元以敕书确认巴蜀自治治事盟约，换取稳定盐粮、茶马供应和地方治理。诸侯共同承担有上限的供额，选出主持者组织公共事务；各家管理自己的钱粮、军队与继承。地方将会盟称为「神圣巴蜀帝国」，中央文书仍称自治治事会盟。

行省公文把「分府治事」抄成「分国治世」，各县争着印国玺，成为开局笑谈。自治的正式依据是经参与者确认的敕书和通商盟约，外部势力通过供额、市场与外交争取利益。背景及规则见[自治盟约与区域隔离](regional_isolation.md)。

成都暂任首位皇帝，但帝位不与成都永久绑定。皇帝自己的国家与帝国是两层权力，诸侯不是皇帝的普通附庸。

四川范围暂按巴蜀盆地及周边讨论，包含重庆。最终地图边界另行确定。开局在范围内，每个可拥有地块对应一个诸侯国；山脉等不可拥有地块保留地形作用。后续战争、继承和统一可以改变领土。

当前候选范围划为七个帝国圈、三十六个府州诸侯组、一百六十四个独立可选诸侯国。帝国圈组织共同事务，府州组提供地方课题，国家保持独立。具体名单见[诸侯层级策划](prince_structure.md)。

### 共有常驻修正：天府之国

帝国地域内所有本地诸侯共享「天府之国」修正，开局一百六十四国全部获得。它体现巴蜀长期积累的水利、耕作与工匠传统，先给各国一份明确的经营优势。

| 效果 | 策划数值 | 作用范围 |
| --- | --- | --- |
| 粮食产出 | +10% | 符合资格的诸侯所辖帝国地域内地块 |
| 本地建造速度 | +10% | 同上 |

两项均为相对百分比修正。粮食基准产出为 100 时，此项贡献为 10；建造速度基准为 100 时，此项贡献为 10，实际工期按游戏速度公式换算。此修正保留各地原有地形与物产差异。

资格按固定巴蜀地块范围和本地政治主体认证，不以皇帝、选侯、圈主持或某一种政体为条件。成员退出会盟、帝国瓦解、更换王朝、改名、释放或重建国家，以及提前统一后，符合资格的本地统治者继续享有；域外国家占有一块地不会取得整国待遇，境外领土也不受此修正影响。

同一地块只应用一份「天府之国」。吞并、继承、迁都、改朝换代与重复执行维护检查都不会增加层数；统一后仍为 +10% 与 +10%。效果贯穿一百二十年及之后，不因五年起业扶持结束或百年任务完成而到期。

地区科技、项目和任务奖励另外按各自规则生效；「天府之国」不增加科技节点、任务或事件计数，也不替代水利维护、粮食储备与灾年经营。制作时采用本地修正，核验原版粮食产出与建造速度字段的效果、显示和叠加方式，再进行平衡试玩。

风味描述：**「地里有粮，城里有匠；诸侯再吵，日子照过。」**

### 前十年的体验

| 阶段 | 玩家面对的事 | 玩家可以做什么 |
| --- | --- | --- |
| 第一年 | 一块地的小国，独立却缺钱缺兵 | 选发展方向，争取盟友，认识皇帝和选侯 |
| 第二至五年 | 首轮帝国茶会，第一场商路或领土争端 | 提议规则，做交易，争取保护，参与仲裁 |
| 第六至十年 | 起业扶持结束，内部邻国争夺与帝位竞争加剧 | 经营小国、争取特殊地位、竞选皇帝或发动内部有限战争 |

默认模式的自治盟约持续保护巴蜀本地国家，阻止圈外主动宣战及通过召集、附庸或继承绕过保护。贸易、知识与非军事外交保留。前五年提供一次性起业扶持；其结束不影响军事隔离。成员之间仍可发生有限战争，吞并独立诸侯会伤害帝国秩序。

小国的第一笔发展收益应足以支持一种玩法选择，而非让所有国家无条件拥有大军。商业、保护和集体工程给弱国生存空间；开局补助仅一次发放。

### 三种长期目标

1. **一县登极**：保持小国规模，以信用和联盟获得帝位，再带领诸侯改革。
2. **富甲巴蜀**：成为受保护的商邦，控制经济影响力，用赞助和议会换取特权。
3. **诸侯归一**：扩张本国，争取皇权改革，最终建立统一国家。

联邦与统一都拥有完成事件和长期奖励。富强的小国可以一直作为小国存在。

## 二 诸侯与七大选侯

### 普通诸侯的活动

所有独立成员可以参与帝国茶会、申请仲裁、接受共同工程、争取选侯资格和挑战帝位。普通成员至少拥有一张议会票，使小国有明确的政治价值。

诸侯可逐步获得商邦、山门或边镇身份。这些是有条件的政治地位，不强制所有国家采用同一种政体。商邦得到保护与经商机会，要缴纳商路经费；边镇得到共同防务支持，要履行驻防任务。身份随对应条件失效而撤销，已经征服大片领土的国家不能一直领取单地块商邦待遇。

### 七大选侯

七个席位开局各有一票，四票构成胜选多数。候选人须为独立帝国成员。席位只授予投票权和有限特权，不禁止其他诸侯成为皇帝。

| 选侯 | 喜剧称号 | 主要诉求 | 玩家争取它的方式 |
| --- | --- | --- | --- |
| 成都 | 盖碗选侯 | 帝国威望、城市繁荣 | 支持公共工程与共同秩序 |
| 重庆巴县 | 山城选侯 | 江运畅通、自治 | 保证通商，克制集中皇权 |
| 富顺 | 盐井选侯 | 盐业收益与经营权 | 选择盐政方案，保护商路 |
| 宜宾 | 酒坊选侯 | 宴会订单、商贸 | 赞助庆典，给予商业承诺 |
| 阆中 | 保宁选侯 | 防务和行政秩序 | 援助边防、履行调停承诺 |
| 峨眉 | 山门选侯 | 山门地位、少受干预 | 保障自治，参与赈济 |
| 雅安严道 | 茶马选侯 | 外贸与交通 | 资助驿路，保护商队 |

这些称号表示玩法身份，不意味着必须把当地原有产物改成茶或酒。

选侯被吞并或长期失去资格后，席位进入空缺。由帝国议会批准替补，皇帝提出候选人。替补优先考虑未获席位的区域代表，防止一个强国控制全部七票。

### 选举体验

默认在皇帝所属国家更换统治者时进行改选。支持度由关系、候选人的义气、军事实力、自治立场和兑现承诺共同决定。玩家能够看到主要赞成与反对理由。

诸侯可以签「茶桌承诺」：我投你，你当选后资助驿路、保护商邦或推动某项法令。每国同时保留一项选举承诺，避免承诺列表无限膨胀。兑现后增加义气和长期支持；违约后扣除义气，受损选侯在下一次选举中明确反对。

若正常多数选举不能产生皇帝，进入一年僵局期。临时议会维持共同防御，暂停改革。僵局到期举行一次限时决选，以有效票最多者胜出；平票由非选侯成员投票裁决，仍相同时按义气和威望依次排序。席位不足时先补位，候选人不足时可由符合资格的唯一成员出任。王朝灭亡与读档都不应让帝国永久卡住。

## 三 皇帝的锅气与诸侯的义气

### 锅气

锅气是整个帝国共享的政治信用，范围 0 至 100，暂定开局 30。它表示诸侯有多愿意让皇帝主持大局。更换皇帝保留锅气，保留已通过的法令。

| 行为或局势 | 对锅气的影响 | 玩法意义 |
| --- | --- | --- |
| 多数成员和平，七席完整 | 缓慢增长 | 秩序有长期收益 |
| 仲裁得到双方接受 | 一次增长 | 皇帝靠解决问题积累权威 |
| 履行内部共同防卫并取得真实成果 | 一次有限增长 | 皇帝保护成员与履约才能得到支持 |
| 成员互战、选侯席位空缺 | 月度增长受损 | 放任内斗会推迟改革 |
| 皇帝侵吞受保护成员或毁约 | 一次明显下降 | 皇权扩张不能白拿公信力 |
| 通过共同改革 | 支出锅气 | 把积累的支持换成制度 |

月度变化按成员比例计算，并设收益上限；创建或释放小国不直接奖励锅气。仲裁与防卫奖励按同一争端设置冷却，防止反复发动假战争刷资源。

锅气达到 60 才能提出重大改革，普通改革暂定花费 35，重大改革花费 50。同一场茶会只处理一项改革。

锅气低于 20 时出现皇权危机：赞助减少、反对派协调更容易、成员更愿意违抗仲裁。低锅气不直接删除帝国，也不会让所有成员自动宣战。皇帝可用让利、赈济和防卫重建支持。

### 义气

义气是各国自己的履约信用，范围 0 至 100，暂定开局 50。它服务于外交与帝国内政治，主要影响选举、仲裁可信度和袍哥合作。

兑现承诺、援助受袭成员和完成共同工程增加义气；毁约、侵吞受保护商邦和无故背弃防卫承诺降低义气。一次行动造成的变化暂以 5 至 15 为主，重大背信可以达到 20。重复援助同一对象有冷却；正常年份缓慢回归中间水平，避免开局一次事件决定整局。

高义气有助于获得支持，但盟友仍会因利益不同反对你。低义气也可凭实力与交易成为皇帝，只是承诺更难被接受。信用与实力形成两条不同的竞选路线。

## 四 帝国茶会与改革分歧

每五年召开一次帝国茶会。皇帝提出一个主要议题，普通诸侯可以提交一个候选议题供议会择优处理。第一次茶会应在开局第三年左右发生，让玩家尽早体验核心制度。

法令投票按国家一票，超过半数的合资格独立成员赞成才能通过；空缺或失去资格的国家不计票。皇帝有提案权而无无限否决权。反对方能读到政策对本国的具体代价。

| 议题 | 支持者想得到什么 | 反对者担心什么 |
| --- | --- | --- |
| 盐税和共同经费 | 为公共防卫与工程筹款 | 盐业与商业成员承担过多成本 |
| 商路与江运 | 降低诸侯之间的贸易摩擦 | 关卡诸侯失去关税收入 |
| 山门与边镇待遇 | 争取长期防务或自治 | 其他成员认为分担不公平 |
| 内部和平 | 安稳发展，防止小国被吞并 | 扩张派丧失机会 |
| 皇帝调兵权 | 更快处理内部共同防卫与严重地区争端 | 军事强国担心承担过重责任 |

为拉票而请客，消耗按本国收入缩放的资金，带来有限短期好感。宴会不能覆盖持续的利益冲突。高成本宴会还会引出盐商索取特权或财政质疑事件。

### 共同改革

先通过三项基础制度，再选择最终制度路线。基础法令可以被后来的议会修订，改动须有成本和冷却。

1. **统一茶钱**：建立公共经费的分摊办法。固定补助转为按实际需求批准的支出。
2. **盐井与驿路公约**：建立可选择的共同经济政策，明确出资者和受益者。
3. **诸侯公断**：承认帝国仲裁。受保护成员遭侵吞时，皇帝可要求归还或恢复其地位。

### 联邦路线

**诸侯各自巴适 → 通商共保 → 巴蜀万国茶会。**

诸侯保留域内独立外交与领土，皇帝的强制权较弱。联合经济与防卫成为主要收益。最终完成事件需要帝国大部分成员支持、商路秩序稳定，并成功处理一次共同防卫、重大商路或财政争端。圈外军事关系按隔离规则管理。

联邦成型后，持续参加公共事务的成员获得贸易和防务便利，义气较高的普通诸侯也能主持共同项目。皇帝每届要接受贡献审查。玩家可以从始至终作为独立商邦完成目标。

### 集权路线

**皇帝统筹锅底 → 共议常备防务 → 巴蜀归一。**

皇帝获得更多经费和共同军务权，但诸侯承担更重义务。集权法令须有三分之二成员支持，并保障反对派的谈判机会。每项法令都提高下一轮阻力，无法靠一次宴会连续通过全部改革。

最终统一要求足够锅气、稳定帝位和议会的特别多数。支持者接受整合；反对者进入有时限的反集权联盟，可争取自治条款、退出或作战。统一并非一次按钮无条件吞并所有诸侯。

两条路线在最终宪章前可通过特别茶会改道，代价是锅气损失和原支持派的不满。最终宪章后路线固定，保留其对应的完成体验。

## 五 巴蜀特色机制

### 盐井公约

盐业国既是财政支柱，也是最容易与皇帝争执的成员。三种政策在收益和权力分配上互相冲突：

| 政策 | 主要收益 | 主要代价 |
| --- | --- | --- |
| 官督盐井 | 公共经费稳定，防卫更容易筹资 | 盐业国利润下降，对集权更不满 |
| 盐商包办 | 盐业投资和经营收益较高 | 商人索取保护与议会影响力，危机时可能罢供 |
| 诸侯分利 | 参加公约的小国获得有限收益 | 皇帝收入较低，收益须覆盖真实分摊成本 |

盐井公约只分配已征收的经费。盐业国不愿参与时，皇帝必须谈判或改政策。经营盐业带来发展事件，但矿井事故和劳资争执会要求持续投入，不能只拿永久加成。

### 茶马驿路与江运

茶马与江运是帝国共同工程。每个工程都有一个主持国、有限的参与成员、资金需求和受益名单。成员出钱、保护运输或提供通行条件，获得收益与义气；拒绝参加保留财政，却无法享受全部项目奖励。

首版提供「茶马驿路」和「川江通商」两个固定项目。后续可以加入都江堰修缮和蜀道整治。项目可被战乱和违约延迟，有维护期和衰退条件，不叠加无限个永久增益。

重庆与成都的争执围绕实际利益展开：江运国要求低过境费，内陆国要求共同修路。两方都有合理诉求，玩家可以斡旋，也可以选边。

### 袍哥与地方利益

袍哥代表地方互助和非正式关系网，采用架空表现。国家可以选择合作、收编或整顿，不增加第三条独立资源栏。

- **合作**：义气高时，地方组织帮助赈济与工程；必须兑现互助承诺。
- **收编**：短期动员更容易，但地方势力要求职位和特权，可能干预选举。
- **整顿**：行政更集中，减少地方干预；短期失去部分合作和支持。

它应让强国也面对关系与治理的代价。通过兑现公共承诺赢得地方支持，是小国与皇帝都能使用的路。

### 麻辣与鸳鸯的政治寓言

「全红锅」与「鸳鸯锅」作为帝国路线的风味表达：前者象征强势统一，后者象征诸侯妥协。正式制度效果仍由宪章决定，宴席选项不能绕开投票。

辣椒、麻将、现代饮食说法可作为明确的架空笑点。首版用「没有辣椒的火锅」自嘲；后续若发展出辣椒传播事件，再解锁相关宴会风味。不同文化和宗教的成员保留身份与合理诉求，不把整片地区写成单一笑料。

## 六 风味事件

### 样例事件  请客的账单

你刚请七位选侯喝完茶，盐商便捧着账本走进来。茶不值多少，贵的是七位选侯各带了一个衙门的人。盐商表示，可以替陛下结账，只要将来盐井的事「少操点心」。

- **「我请的客，我付。」** 支付一笔显著的收入比例费用；得到短期好感与少量义气，不附带政策义务。
- **「盐井的事，你们确实更懂。」** 减少本次支出；向盐商承诺一项经营特权，限制下一场盐政选择。违约触发追债与失信。
- **「各人付各人的。」** 节省费用；本次宴会拉票收益取消，部分选侯暂时降低支持。

选择结果显示影响对象、持续时间和承诺期限。盐商特权到期后重新谈判，不永久锁死国家。

### 样例事件  川江多了一道卡

参与川江通商的诸侯刚签完公约，一位成员就在下游设了「临时便民收费处」。过往船只并不方便，收费倒很方便。商人要求皇帝做主，设卡诸侯则表示，自己的财政也有难处。

- **「公约写得清清楚楚。」** 要求撤卡；成功后工程恢复，设卡国不满。被拒绝则进入有限仲裁，皇帝可以让步或进一步追责。
- **「少收点，帝国补一点。」** 支付有上限的补偿；工程恢复较慢，设卡国保留部分收益，其他关卡国可能要求同等待遇。
- **「这是地方事务。」** 保留成员自治；工程收益暂降，出资成员降低对皇帝的信任。

事件不会凭一次选择直接替国家转让地块。选择应能引出不同的外交后续。

### 样例事件  成都与重庆谁坐上席

茶会还没开，座位已争了三天。成都使者说，上席自然应留给皇都；重庆使者说，川江往下流，椅子为什么不能轮流坐？其他诸侯开始计算，拖到明天能不能省下一天住宿费。

- **「这回成都，下回重庆。」** 采用轮值会址；地方成员支持提高，皇都派反对。会址变化仅带来有限声望与项目机会。
- **「帝国总要有个固定会址。」** 将会址固定；议会筹备更稳定，自治派与江运派支持下降。
- **「谁承办，谁出席面。」** 邀请成员承办；承办国出资换声望，富裕商邦更容易得到主持机会，小国担心议会被财富垄断。

三种结果提供不同支持联盟，不设长期通吃的最佳选项。

地区事件与科技实践进一步组成任务线，详细触发、分支选择及后果见[地区事件与任务策划](regional_missions_events.md)。本节与地区文档中的同名事件复用内容，投递给正在参与该事务的国家。

## 七 战争与反对派

内部战争保留扩张乐趣。初期皇帝能调停和保护特殊成员，不能自动拉整个帝国围殴每个进攻者。保护战争以恢复成员与履约为目标，普通的边境争夺不会自动升级为全帝国内战。

默认战役限制圈外主动宣战和巴蜀主动发动圈外战争，外部军事依附与参战入口一并隔离。界外市场、供额和使团提供长期压力；内部兼并、保护、反吞并及反集权冲突继续作为战争内容。隔离贯穿百年，提前统一、改选或成员退出不自动解除保护。

吞并独立成员比夺取普通领土更容易引起共同反对。皇帝也受到此规则约束。强国可通过赔偿、恢复小国和议会交易缓解压力；拒绝和解则面对逐步组织起来的反吞并联盟。

集权推进过快时，反对者结成「各吃各的联盟」。联盟提出实际条件，例如固定自治、限制公共税费或重审皇帝调兵权。谈判成功可以延缓改革并恢复锅气；战争胜利不能免费跳过所有改革。

成员可以在明确条件下退出帝国，失去共同保护、工程收益和投票权。退出不立即触发所有成员敌对。皇帝争取其回归时要给出新的利益安排。

## 八 人工智能与反刷设计

各国按局势表现为务实商贸派、自治派、皇权派、山门保守派或军事扩张派。立场来自规模、收入来源、地位与受威胁程度，能够变化。首版应让玩家看懂反对理由，而非要求玩家掌握隐蔽评分。

- 缺钱的小国优先稳定财政和寻求保护，避免为了皇帝的宴会集体破产。
- 商贸派支持通路，面对强征盐税时转向反对。
- 大国支持共同防卫，但对让皇帝控制本国军务更谨慎。
- 被帮助过的国家更信任援助者，也会在援助者后来吞并邻国时重新判断。
- AI 的选票由持续利益决定；重复送礼与同一事件好处有递减和冷却。

同一争端只结算一次主要奖励。公共项目补贴随参与成本和真实贡献发放，释放小国、交换地块、改换皇帝与读档都不能重复领取。大范围政治结算按年度或茶会进行，减少无意义的每日重复判断。

## 九 原型与完整版本范围

### 第一阶段  一县也能活

完成一百六十四个候选地块的诸侯开局、七选侯与帝位轮替、长期区域隔离和基本生存支持。逐国确认能选择和起步，再用一个普通小国和一个选侯分别试玩，前五年应能发展、结盟并参与一次共同事务。

### 第二阶段  皇帝有事做

加入锅气、义气、帝国茶会、三项共同改革，以及十二个优先事件。皇帝要能通过仲裁、工程和防卫积累支持；普通诸侯要能用选票和贡献换取具体收益。

### 第三阶段  巴蜀有自己的味道

加入盐井公约、两个固定商路项目、袍哥三种处理方式，以及两条制度终局。先用清晰的制度反馈表达特色，再决定是否扩展专属界面和大量地方内容。

同时加入地区科技原型：三项共同进步，以及七个地区各两个基础节点、两项互斥的专精入门，共三十一个候选节点。玩家研究前能看到地区专长、解锁行动与对应成本；完整地区树随后扩展至六十四个节点。具体内容见[地区科技树策划](regional_technology.md)。

地区内容原型配套二十八项任务与二十一个事件，覆盖每地区两项共同准备、两种专精入门及早期冲突。高级科技开放后，继续加入分支深化、终点和跨区联合，完整地区内容蓝图为六十项任务与三十九个事件。

### 第四阶段  百年事业继续经营

加入二代交班、旧约审查、晚期适应与百年改章，共五十项长期任务和四十个长期事件。完整内容合计一百一十项任务、七十九个事件，并以二十一类委托持续提供日常经营。满百年后的宪章验收要求真实维护与地区贡献，提前统一的国家继续以本国地区机构承接事业。完整风味包验收包含本阶段；前期原型用于内部验证。

| 试玩问题 | 首版应达到的效果 |
| --- | --- |
| 普通单地块诸侯前五年有事可做吗 | 能经营、争取保护、参与茶会；不必吞并邻居才有进展 |
| 小国真有机会成为皇帝吗 | 用几轮履约与联盟能够赢票，不由开局领土直接决定 |
| 皇帝是否只有收益没有责任 | 防卫、仲裁、筹款和兑现承诺都消耗真实资源 |
| 盐业、江运与山门的体验有区别吗 | 同一法令对它们的利益不同，事件与合作选择不同 |
| 联邦路线有没有长期目标 | 可完成联邦宪章，商邦能以独立身份获得完整结局 |
| 不断吞并是否永远最优 | 扩张有收益，也会损失选票、信用和共同保护 |
| 事件能重复玩吗 | 触发与政策局势相关，有冷却和不同后续，奖励不会无上限叠加 |
| 玩家会不会被弹窗淹没 | 普通年份最多一至两次主动地方事件，政治转折年可适当增加 |
| 同地区的诸侯是否只能走同一路线 | 每条地区树有两种专精，选择由财政、局势与长期目标决定 |
| 单地块国家与跨区强国能否都使用科技 | 小国靠本乡技术提供服务，大国靠交流与地方机构组织跨区合作 |
| 玩到八十年和一百一十年是否仍有新内容 | 晚期调整和百年改章读取旧账与制度，持续提供地区及跨区目标 |
| 提前统一会不会结束风味内容 | 地区机构承接原事业，在国内继续处理经费、代表与治理权限 |
| 大元或圈外强国能否绕过保护宣战 | 核验普通、特殊、事件宣战及所有参战入口，默认保护贯穿完整战役 |

首版重点是把「经营一个县、参加一次茶会、争取一次帝位、选择一种帝国未来」连成完整体验。

## 十 地区科技与合作

地区科技由共同进步和七条本乡树组成。共同进步发展账簿、工艺传播和交通协作；地区树从两项地方基础分为两种专精，每支继续深化至地区终点。科技解锁新的课题、契约和主持资格，议会表决与履约仍决定实际收益。

| 地区 | 两种专精 | 参与帝国的方式 |
| --- | --- | --- |
| 成都平原 | 水利粮政或学宫议政 | 组织水利、赈济、知识传播与议事 |
| 川南盐酒 | 盐业融资或宴席经营 | 用贷款、经营特权和采购合同影响诸侯 |
| 重庆川东 | 江运通商或江岸守备 | 主持运输、关卡协商和沿江防卫 |
| 川北蜀道 | 关隘联防或驿传行政 | 承担防卫、通行与公文服务 |
| 川中丘陵 | 义仓互济或契约公信 | 救济小国，为诸侯交易见证与核账 |
| 川西茶马 | 茶马商路或山门调停 | 组织商队，协调通路与地方自治 |
| 川西南山谷 | 山谷商盟或地方共治 | 组织谷地互市，共同议约与防卫 |

普通诸侯主修一条本乡树，可通过技术交流维护一个客座地区。客座学习基础与一项入门专精，地区深化和终点由主修提供。跨区统治取得当地设施收益；国家级主持地位依靠持续投资与履约取得，迁都与统一保留知识并重新确定正在维护的制度。

详细节点、解锁条件、机会成本和事件衔接见[地区科技树策划](regional_technology.md)。

## 十一 地方事业与帝国政治

各地区按「研究本级科技、完成实践任务、取得下一阶段研究认证」推进。每地区两项共同准备后分为两种专精，各支三项任务；普通诸侯凭完成事业争取公共委托和政治地位。

| 地区 | 主要任务事业 | 连接的特色机制 |
| --- | --- | --- |
| 成都平原 | 水权分配、粮食互济；讲会、章程与学宫 | 都江堰水权、帝国茶会、知识传播 |
| 川南盐酒 | 井灶维护、盐引融资；宴席采购与结账 | 盐井公约、皇帝欠条、加冕赞助 |
| 重庆川东 | 通行费协商、运输互保；江岸补给与守备 | 川江关卡、公共商路、共同防卫 |
| 川北蜀道 | 关隘轮戍；通行驿券与公文送达 | 蜀道通行、边镇义务、帝国行政 |
| 川中丘陵 | 储备借粮；合同见证与欠款清算 | 义仓、袍哥人情债、盐引核账 |
| 川西茶马 | 商队互保与会约；施济及跨地调停 | 茶马驿路、地方信任、帝国仲裁 |
| 川西南山谷 | 谷地互市；驻防议约及权限审查 | 山谷商盟、地方共治、宪章保障 |

任务中的贷款、供水、通行与驻防采用有期限、权责和恢复路径的合同。袍哥人情债以具体互助承诺记录，每国同时保留至多三项：约定支援、工程贡献或政治协商等回报。义气反映履约，选票仍由成员决定。兑现、明确接受的修约或双方同意的减免可结清承诺；违约引出补偿与信用后果。

四项跨区事业分别为盐船共账、天府分仓、茶马过蜀道和谷地共保约。参与国各用自身科技承担一个角色，按真实合同结算。同一项目既能服务地区任务，也能进入帝国政治，资源与公共功劳只登记一次。

联邦宪章承认各地区的服务与独立地位；集权改革需要处理债务、经费、通商和地方治理保障。任务取得谈判筹码，正式制度仍由议会与改革流程决定。详细内容见[地区事件与任务策划](regional_missions_events.md)。

每地区继续增加两项传承共同任务及每支两项晚期任务。满百年后，各自完成水利、盐债、江运、关防、义仓、茶马或地方共治章程；早期制度的受益者、新参与者与主持机构重新谈权责。相关内容见[百年经营与地区传承](century_campaign.md)。
