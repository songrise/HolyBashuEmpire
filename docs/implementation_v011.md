# 神圣巴蜀帝国 0.1.1

## 玩家可见变化

- 64个课题从决议菜单迁入原版科技树：8公共、7圈各8项；每国可见自己的16项。精灵图器物图标用于科技节点。
- 新研究走原版队列，成本档为1.5/2.5/4.0；保留1337、1342、1352、1372、1397年代门槛、前置与A/B互斥。
- 旧变量和原版科技每月同步。已有课题不再发一次奖励；旧计时课题继续完结。迁移保持原版研究进度，由原版队列负责新课题排程。
- 70项非科技决议保留独立配图，导出1080×440以匹配原版540×220图框；主体保持纵横比例。
- 修复70项决议隐式标题键，并为每项补充两段风味正文及单列规则说明。
- 36面旗帜使用白底黑色隶书简称，保留各自纹章和旗色。
- 36府州有独立背景介绍，连接国家描述与开局选国介绍。历史地理与地方传统为背景，诸侯政权、会盟敕书及政治处境为架空。
- 70决议登记国家标签、国家专属类别；36国专属一次性事件补原版DHE索引；事件总数仍96；64课题注册原版advance。国家特色及内容分类由原版数据读取，不修改原版汇总GUI、不伪造建筑或兵种数字。

## 核对入口

关闭旧游戏后重新启动模组。科技树查找“乡约与账簿”或本圈第一项课题；使用传统时代筛选或全部显示。
国家“内容”页应显示本国可用特色决议、事件与科技分类；“描述”页查看国家历史。各分类统计受原版当前国家、时代与可用内容筛选影响，不代表每国能够使用全模组64科技、70决议与96事件。
如旧存档仍有决议课题计时，新课题须待其结算；已完成课题在下一次月脉冲同步入科技树。

## 登记与实现

科技：`in_game/common/advances/hbe_advances.txt`；地区条件使用具体国家标签，防止普通四川文化国家取得整个树。`starting_technology_level=99`阻止中国模板开局科技等级3预授予新增课题；乡约与账簿接原版文字知识，各圈基础课题、匠人互访与驿路勘绘接乡约与账簿。`requires`构成原版节点连接，`allow`保留年代、帝国成员及分支互斥条件。
同步：`hbe_native_content_effects.txt`和`hbe_native_content_on_actions.txt`；只有新取得课题变量时才发义气/锅气完成奖励。课题的具体资格用途在原版节点提示中列明。
决议：原版读取`<key>.title`，并在内容目录使用`.title.entry`和`.desc.entry`。两套语言目录均补完整键；英文UI目前仍提供中文内容。
事件：36国专属事件用`dynamic_historical_event`、`fire_only_once=yes`登记原版历史目录，`monthly_chance=0`防止重复调度，并补齐`.entry`标题。原版历史目录要求一次性事件，其余60个共享或循环事件保留原调度，避免破坏三年结算、账本和地区循环。
国家背景：`country_history_TAG`与自有`country_description_categories`。资料和可读稿分别见`data/native_content_v011.json`及`docs/country_biographies_v011.md`。

## 验证范围

结构检查见`validation_v011.json`。引擎测试验证原版科技授予、变量同步、已完成旧课题不重复奖励、旧计时结算和局势成员注册；运行结果见`runtime_v011.json`。
无界面测试不能证明图框最终观感、旗面布光和原版汇总栏当前数字，GUI须在玩家游戏中验收。百年平衡未完成实机跑测。
旧研究计时兼容分支保留旧变量，在debug日志可能被“used but never set”检查报告；新版本不再主动建立这些旧计时变量，保留它们用于读取旧存档。
