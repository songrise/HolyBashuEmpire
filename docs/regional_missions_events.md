# 神圣巴蜀帝国地区事件与任务策划

地区任务把科技转化为具体事业，事件让这些事业遇到利益冲突。每条地区线先完成两项共同准备，再选择两种专精之一，用三个分支任务取得相应主持资格。玩家从一块地出发，也能靠供水、融资、护运、守关、赈济、见证或地方议约参与帝国政治。

本文为地区起业与专精骨架，包含五十六项地区任务、三十五个地区事件，以及四项跨区任务与四个跨区事件。每个地区的基础部分有八项任务和五个事件；一国通常经历两项准备任务与所选专精的三项任务，再继续完成传承与百年内容。主玩法与科技文档中已有同名事件采用本方案细化后的版本，作为同一事件引用，数量不重复相加。

完整内容按至少一百二十年设计，后续接[百年经营与地区传承](century_campaign.md)的二代交班、旧约重审、适应性调整和百年章程。完整蓝图共一百一十项任务、七十九个事件，并有二十一类持续经营委托。

相关策划：[主玩法](gameplay_design.md)、[地区科技树](regional_technology.md)。本文中的科技、条件和效果均为玩法设计目标。

## 一 任务与科技的联动规则

### 一条任务线如何推进

基本循环为：**研究地方节点 → 开始对应任务 → 实际投入并处理事件 → 取得实践认证 → 开放下一节点的研究条件**。实践认证提供研究资格，下一节点仍需正常投入研究。

每地区的「共一」为起步任务；「共二」以前者完成为前置。完成共二后进入专精选择事件，决定主修 A 或 B。所选分支按一、二、三顺序推进，每项同时要求研究其对应科技。

任务条件按行动记录判断。资金、粮食、通行、防卫、知识交流等贡献，以同一份合同或工程账目结算一次。项目完成、款项还清、协议履行等事实取得认证；更换皇帝、读档和更换主持国保留这些记录。

### 普通小国如何完成

地方起步工程可在本国完成。后续合作优先邀请附近独立成员，费用按国力与承担角色缩放。单地块国家可以只承担出资、见证、运输协调或地方维护中的一项，贡献要求由选定角色决定。

没有合适伙伴时，允许通过本地行会、商队或地方机构完成规模更小的试办任务，取得同阶段实践认证。帝国委托、跨国分摊和共同防务的完整待遇，须再取得真实成员参与；任务界面分别显示「地方试办」与「帝国承办」的条件。

川南没有盐井的国家可沿宴席分支发展，或通过稳定的盐业合作合同承担盐政管理角色。川东内陆成员通过陆路接驳参与江运，川北非关隘地块通过后勤参与联防。地方资格与任务角色匹配，适用地块的生产与守备效果按地理条件生效。

### 完成奖励与后续责任

- **基础任务**：取得实践认证、一次有上限的补助或关系收益。
- **专精任务**：开放合同类别、参与名额或议题资格，并取得深化研究条件。
- **终点任务**：取得地区从业资格和一项需维护的公共委托；承办所得按当前合同和贡献发放。
- **帝国效应**：被议会认可的公共成果可以增加有限锅气，履约者增加有限义气；地方试办主要获得地方收益与实践认证。

地区终点任务可由多国完成。同领域的帝国委托通过投标、轮值或议会决定当期承办国，其余合资格国家仍可参与或竞争。取得资格的国家不自动成为选侯；获得选侯席位仍遵循帝国补位规则。

### 事件与失败

关键事件由开始合同、年度履约检查、任务验收或政治转折触发。灾年、真实战争等局势可以提供特殊版本；常规的预算审查、试运和防卫演练提供可按计划完成的版本。

一次任务事件通常允许足额履约、协商修改或拒绝承担三种处理。修改条件需对方同意。失败后暂停相关合同收益，进入补缴、修复、重议或更换伙伴的恢复任务。恢复完成可继续推进；同一阶段实践认证只发放一次。

原有科技及专精更换规则继续适用。换专精归档旧支任务，终止其制度待遇并结算未履行合同。迁都、被吞并、退出帝国与伙伴消失均保留已有认证，当前委托按成员资格与合同重新安排；已取得的知识不会因任务暂停被删除。

每国同时推进一项地区任务和一项跨区联合任务。已有合同可以按约继续维护，新的公共委托受承办能力和预算限制。事件中的高级选项要求对应科技；同名事件的早期版本处理维护、试单与地方协议，深化版本处理盐引担保、互保基金或正式驻防，任务提示显示具体门槛。

## 十 任务与帝国终局

### 联邦路线

完成共同基础法令后，具备地区资格的国家可以为联邦宪章提供一项经认可的公共贡献。组织一次跨区项目、持续维护一项共同服务或履行一份防卫协定，均可计入贡献。

同一项工程的各方按真实角色记贡献，帝国层面的成果只登记一次。达到参与广度与秩序目标后，可以提交「巴蜀万国茶会」宪章。各地区机构保留独立地位，今后承办需要轮值、竞争与议会支持。

### 集权路线

皇帝推动集中军务与统一时，地区主持国提出对应保障：盐业要求债务被承认，水利要求按约维护，关隘要求经费，商路要求稳定费率，义仓要求储备边界，山门与谷地机构要求明确治理条款。

皇帝可接受保障换取支持，或谈部分让步；单方面拒绝使受损地区更容易组织反对。完成地区任务带来具体谈判筹码，不能直接跳过帝国改革。统一后地方设施与真实合同继续结算，国家级终点待遇按科技树的主修规则选择。

## 十一 完整联动示例

以一个普通富顺盐业小国为例：

1. 研究井灶公账，完成「井灶账算清」，取得协作实践认证。
2. 研究盐酒作坊协作，完成「盐酒拼一单」，在事件中选择盐业融资。
3. 研究井灶改良，完成「井灶有章法」，取得盐引深化资格。
4. 研究盐引担保，接「皇帝也要按时还」，向一项川江公共工程提供资金。
5. 川东伙伴负责运输，双方开展「盐船共账」；川中伙伴可担任合同见证。
6. 「盐商请陛下画押」或联合结算事件检查真实债务：偿还获得信用，展期须谈条件，拒付则产生追偿。
7. 完成A二认证后研究巴蜀盐业总号，结清更多合同并通过总号任务验收，获得下一轮公共融资投标资格。
8. 皇帝推进集权时，该国可要求承认未清债务作为支持条件；也可以支持联邦，继续保持独立融资地位。

同一份贷款贯穿科技实践、地区任务、跨区合作与帝国政治。收益来自真实出资和偿还，政治影响来自信用与仍有效的合同。

## 十二 原型与百年完整版本

地区原型与现有三十一个科技候选节点配套：先制作每地区共一、共二、A一、B一，共二十八项地区任务，以及专精选择与两支早期冲突事件，共二十一个地区事件。每条早期任务线都能从起步走到一次特色机制实践。

在原型阶段，融资合同、互保、驻防等深化机制先展示筹备和地方试办；正式高级资格需要第二阶段科技与任务。第二阶段加入另外二十八项地区任务、十四个地区终点事件，以及四项正式跨区任务和四个跨区事件，完成全部六十项任务与三十九个事件的蓝图。

第三阶段加入五十项长期任务与四十个长期事件，按[百年经营与传承策划](century_campaign.md)完成至少一百二十年的内容跨度。原型用于内部验证经营循环；完整风味包的范围包括中期、晚期与百年任务。研究窗口、定期经营、旧账连续性及提前统一后的国内治理共同支撑长期体验。

与主玩法事件池重复的同名事件复用同一条内容，不额外计作新增事件。原型事件也按玩家所在地区、当前任务和实际受影响对象投递；一次争端只生成一份主要事件记录。

| 验证问题 | 应有的玩法表现 |
| --- | --- |
| 科技和任务会不会互相卡住 | 每一步是先研究本级节点，再完成实践开放下一级；不要求先学待解锁节点 |
| 每地区两支是否各有意义 | A与B有不同的经营对象、责任和帝国谈判筹码 |
| 单地块国家能否从头走通 | 贡献按角色与国力确定，地方试办可取得阶段认证 |
| 合作对象拒绝或灭亡怎么办 | 可重议、补偿、更换伙伴或转地方试办；已取得认证保留 |
| 会不会等待几十年才有事件 | 年度检查、试运、验收和演练提供正常触发；灾年与战争提供特殊版本 |
| 任务是否只奖永久数值 | 核心奖励为研究条件、从业资格与有责任的公共委托 |
| 皇帝是否获得所有公共功劳 | 贡献公开登记，普通诸侯可以主持和获声望 |
| 反复释放国家或签约能否刷奖励 | 认证一次发放，同一合同按事实结算，公约和身份待遇按当前资格计算 |
| 两条帝国终局是否都能衔接 | 联邦承认地区服务，集权需要解决各地区具体保障与旧合同 |
