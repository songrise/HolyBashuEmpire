# 0.3.0 本地修订

本次保持版本号0.3.0，仅更新本地安装。创意工坊继续保留已发布的版本。

- 80项特色科技的永久数值加成、14项科技条件联动及科技附加事业收益降至原来的80%；15项课题改用识字、阶层满意度、地方控制、制度传播、文化和宽容等收益。
- 审计科技不再登记全部七圈的14种建筑和7种兵种。签订各圈客籍议约后，分别取得该圈的自动资格凭据；保留当地领土、供养、招募容量等限制。
- 每圈红框两条路线的四项科技，共28项，从第一时代移到第二时代；第二时代保留逐级分支。部分路线接在原版金融、立法、书记簿册、招募、操练及补给节点之后。
- 川江、蜀道两种升级兵种的基础战斗力分别提高到1.20与1.15，保留500人编制，并增加补给负担。
- 修复大开席成员行的宽度及容器结构；行动直接绑定玩家国家，并保留原版合法性检查和条件提示。
- 增加“地方事业”及“派内分红”悬浮指南，解释入口、工期、费用、贡献时点与具体项目。
- 换派五年内限一次；原派其他成员对离开国态度−5，每年恢复1点，最多五年。
- 每两年结算：每位贡献国增加半个月税贸收入的帝国奖金，最低8、最高64金币；再加上实际出资的25%，按ln(1＋贡献)权重分红。奖金直接生成，不额外扣取成员国库；每派另分3点威望。零贡献不增加奖金也不领取，事业贡献者同样可分金币和威望。
- 三十六府之间默认建立一年双向停战；七圈自动互相防卫，主动进攻不自动召集同圈。大开席最早启动日期提前三个月至1337年7月1日。
- 开局每位统治者获得同文化、同宗教配偶；随机0—3名合法后代，含成年子女，年龄上限按父母年龄分为16、20或24岁。父母生育年龄至少16岁；零后代仍有继承风险。
- 修复开局子女三项能力全为0：新生成子女分别随机20—70行政、外交、军事能力。旧档由加载或月初的一次性补丁补齐原开局统治者仍在任时的全零存活子女，不重掷已有能力。

开局家族与停战仅在1337年开局初始化，旧年份存档不补发新的停战，也不覆盖已有家族。旧存档的已研究科技保留，跨圈资格在加载或月初补齐。新开局项目建议开新档体验。

科技前置参考安装的EU5 1.4.0 `in_game/common/advances/0_age_of_renaissance.txt`；战争协作参考原版组织的防御战争字段；婚姻、生育和停战沿用原版事件效果。

验证范围、运行结果与已知限制见本次独立的本地测试报告。无图形运行可检查脚本及数据，不代替实际界面像素验收。
