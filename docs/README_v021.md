# 神圣巴蜀帝国 0.2.1

EU5巴蜀架空历史风味包：一个帝国、七个帝国圈、三十六个可选府州诸侯，合计164个地块。适配EU5 1.4.*，建议新开1337年存档。

## 本次更新

- 80项特色科技全部获得研究完成即生效的原版加成，直接显示数值和解锁；保留两时代分布与地区互斥专精。
- 16种地区机构强化，新增14种原版生产方式：锦坊织锦、井架联灶、江船备料、驿券纸坊、仓社附田、商队皮作、诸谷农具。
- 14种地区合作收益，连接科技、有效机构、近五年完成的地方事业、地区储备和役负；断供或条件失效时暂停。
- 大开席只设共建派与兴业派，每两年结算；出资记1贡献，完成地方事业记2贡献。参与立即获益，共同成功和领先派另有奖励。
- 局势界面使用原版双领袖模板、两派成员列表与贡献条；出资和改派接入原版局势行动区。
- 1342年起，休养充分的AI更愿意竞争邻府，异派竞争略强；保留原版战争风险判断、停战、盟友关系与外围隔离。

## 七圈玩法

|地区|主要收益链|
|---|---|
|成都平原|渠田粮政；锦坊分工与官学文化，两条专精各有联动|
|川南盐酒|盐井产出、盐引融资、信用与酒坊宴席经营|
|重庆川东|转运船帮与商人容量；江岸守备及军费供养|
|川北蜀道|道路、驿券与制度传播；关隘轮守和补给|
|川中丘陵|粮食保存、义仓赈贷与乡社清算|
|川西茶马|茶业、驮具与商队互保；山门调停和文化交流|
|川西南山谷|农具生产、谷市交换；乡寨共保和地方承受能力|

本版按强势风味包设计。科技永久收益、实际运营的建筑收益和条件合作收益可以叠加；同名局势奖励刷新持续时间，不按届数无限叠层。

## 安装与入口

1. 解压后运行Install-Mod.ps1，或将holy_bashu_empire文件夹放入游戏用户目录的mod文件夹。
2. 在EU5模组管理器启用本包并应用播放集，新开1337年游戏。
3. 特色科技进入原版科技树；机构在原版建设菜单，9种特色军在原版招募菜单。
4. 国家内容页保留地方事业、阶段任务、府议、民役政策和五年委任；大开席可直接在局势面板选派与出资。

域内天府加成维持粮食生产+10%、建设速度+10%。36国背景、无文字纹章旗帜与现有插画保留；新生产方式使用原版商品图标。兵员与建筑使用原版3D资源。

## 大开席收益

出资费用为月度贸易与税收收入的35%，最低2、最高6金币，每国每届一次。完成地方事业也可参与，每国每届记一次2贡献；两种贡献可以并存。

参与立即获得两年建设速度+15%、商人容量+15%。共同达标后，贡献国得到6金币、3声望、5信誉和三年生产效率+15%、粮食生产+15%。领先派的贡献国再得三年专属支持：共建派建设+20%、粮食+15%；兴业派商人容量+25%、文化影响力+20%。平局两派均获额外支持。开局目标12贡献，成员减少时相应降低，最低3，统一后仍可继续。

未达标不扣信誉、不追债，参与收益保留。改派有五年间隔，不重领奖励。两派不自动参战、不增加皇帝选票。1437年后，完成至少六届成功合作可形成长期安排；地区课题与故事持续到1457年之后。

## 版本与验证

本版沿用国家编号和地块名单。旧存档第三派转为兴业派，并重新开始一届；已有地方事业计时保留。请先备份旧存档。其他修改1337年领土的模组可能冲突，初次游玩建议单独启用本包。

针对性检查：[检查记录](docs/validation_v021.json)。新增机制独立引擎用例见[机制验证](docs/runtime_v021.json)。双领袖界面的最终视觉排版和百年平衡仍需实际游玩检查。

详细规则：[科技与产业](docs/technology_rewards_v021.md)、[简化大开席](docs/simple_banquet_v021.md)、[内部AI战争](docs/ai_internal_wars_v021.md)、[府议与军队](docs/social_expansion_v020.md)。117条事件定义和97项决议登记保留，旧大开席复杂入口隐藏，部分旧事件仅保留兼容。
