# 神圣巴蜀帝国自治盟约与区域隔离策划

默认战役以巴蜀内部政治和地区经营为核心。圈外国家不能主动对受保护的巴蜀国家宣战，也不能通过召集、附庸或继承把它们拖入外部战争。保护贯穿至少一百二十年的内容，并持续到之后；第五年、百年任务完成和更换皇帝都不会自动解除。

背景采用架空的「巴蜀治事与通商自治盟约」。大元确认地方自治，以稳定盐粮、茶马供应和边地治理换取诸侯共同履约；其他周边势力承认其通商与缓冲价值。地区仍能与外界进行贸易、知识交流和使团往来，外交军事领域则按默认隔离规则管理。

本文规定玩法目标与制作验收要求。条约、宣战及参战限制需在制作阶段核验所有战争入口，正式隔离效果以游戏内验证为准。

## 一 合理背景

### 大元为何同意

设定中，蜀地此前的征税、运输与边地管理长期存在开销和欠账。朝廷与地方达成治事约定：各县城和地方机构被承认为自治诸侯，共同承担有上限的供额；巴蜀会盟负责组织缴付、维护道路和处理内争。大元得到稳定供应，地方获得明确自治。

山地运输、守备和地方合作的成本，使直接接管未必比既有供额更合算。盐业融资和共同工程进一步把地方机构变成朝廷与外部商人的重要合作方。盟约的形成依靠成本和利益交换，而非外部国家突然放弃扩张意愿。

「神圣巴蜀帝国」是地方会盟自用的宏大称号。中央敕书将其记作巴蜀自治治事会盟，承认其选举产生的主持者。公文把「分府治事」抄成「分国治世」保留为开局笑谈；自治的正式依据是双方已经确认的盟约。

名义供额通过事件和合同表达，诸侯在游戏里维持独立政治主体，外部军事依附按隔离规则管理。

### 周边势力为何承认

巴蜀成为各方参与的中立贸易与运输区。周边商路、市场、债权人与地方协议绑定；破坏自治会伤害多个参与者的利益，还可能把竞争势力引入山地。外围势力通过使团、采购、贷款、供额谈判和通行条款争取利益。

大元衰退、政权更替或地方军阀兴起时，既有合同与供应利益由后续参与者接续。巴蜀会盟组织一次承认或改约事件，调整关系和经费，但默认军事保护仍有效。盟约在设定上承接外部变化，游戏规则为内部战役提供明确边界。

## 二 默认隔离规则

| 场景 | 默认规则 | 内部玩法如何保留 |
| --- | --- | --- |
| 圈外国家向受保护巴蜀国家宣战 | 阻止玩家、AI与事件发起的常规外部宣战 | 巴蜀国家之间可按帝国法令开战 |
| 旧领主使用原核心、声索或征服理由 | 开局将域内收复权转为背景供额和合同权益；宣战入口仍受保护 | 原争议通过供额、债务和使团事件处理 |
| 巴蜀国家加入圈外军事同盟或外部附庸关系 | 默认不开放会绕过隔离的军事依附和参战关系 | 域内同盟、保护、联防与政治依附按本包规则运行 |
| 圈外战争召集、参战或强制战争继承 | 检查所有入口，受保护国家不能因此成为外部交战方 | 既有运输或供额可能受市场和外交事件影响 |
| 国家改名、改政体、王朝更替、皇帝改选 | 保护资格跟随域内政治主体，不依赖某一个固定国名或王朝 | 地方合同与任务正常传承 |
| 帝国瓦解或成员退出 | 域内保护地理与本地国家认证继续生效 | 国家失去帝国共同待遇，仍能经营和重建会盟 |
| 玩家提前统一巴蜀 | 统一国家继承自治地位与保护 | 原诸侯事业转为地区机构治理 |
| 默认模式下巴蜀向圈外主动开战 | 同样限制，避免制造外部反击与盟约漏洞 | 主要扩张范围为巴蜀保护域内 |
| 外界贸易、采购、知识交流和使团 | 保留非军事往来 | 外部变化成为经济和制度调整的内容 |

保护域采用固定候选地块名单，国家资格按其本地立足与自治状态认证。界外国家不会因短暂占有一块地自动取得整国保护；本地国家跨域移居也不会把保护无限带向世界各地。制作时要明确重建、释放、继承和统一的资格判定。

暂定一百六十四个候选地块构成初始保护域，详见[诸侯层级策划](prince_structure.md)及[候选名单](data/prince_roster_draft.csv)。保留地图、物产和对外商业联系，隔离规则约束军事关系。

## 三 供额与外部压力

供额是国家外交与帝国财政的背景合同，按帝国认可的办法分摊，有上限、有期限并能审查。普通小国可用采购、维护和运输角色贡献，避免所有单地块国家都背上相同的重税。

| 外部问题 | 玩家选择 | 可能后果 |
| --- | --- | --- |
| 朝廷使团要求增加供额 | 筹集有限追加款、谈期限、提交真实成本 | 财政与外交关系变化，引出内部公平分摊争议 |
| 外部采购方拖欠货款 | 展期、共同追账、依法终止合同 | 经营收益暂停、债权调整与后续信用变化 |
| 外部市场或运输条件改变 | 改线、转产课题、投资维护、缩减业务 | 晚期商路与盐业任务出现新目标 |
| 政权更替后的承认文书 | 重申旧约、经参与方同意修约、提出地区保障 | 改变供额、关系与议题，保持默认军事保护 |
| 供额未按期履行 | 补缴、减额协商、债务重整或承担经费责任 | 损害信用与当前经济待遇，触发恢复任务 |

外部压力影响实际经营与帝国内部分配。拒绝供额不会自动触发大元入侵；它会使信用、采购条件和共同政治支持恶化，玩家随后需要处理欠账与恢复合作。

## 四 防务路线在隔离模式中的作用

关隘、江岸和地方共保主要保护巴蜀内部成员、商路及运输节点。内部战争、反吞并联盟和反集权政治军事冲突仍可出现；防卫承包、轮戍和应援因此有实际价值。

边地检查、巡察和演练提供和平年份的实践任务。锅气奖励按公共履约和真实成果发放，演练只取得相应实践与有限信用，不按对外战争胜利发放奖励。

此前设计中以外敌入侵为必需的任务条件，改为内部共同防卫、重大商路争端或受认可的财政压力处理。地区军事科技继续强化适用地形、补给和履约能力，百年任务无需等待一场外部战争。

## 五 事件与百年内容的联动

主玩法的开局事件交代自治敕书和内部会盟。百年事件「新皇登位，旧债先到」同时读取供额与对外采购合同；「外面的生意变了」读取市场条件；「半世纪旧约新议」和「百年巴蜀宪章」处理供额分摊、旧债与地区治理保障。

大元与其他外部强国作为外交、市场和政治背景参与战役。新压力通过已有事件的外交版本投递，不凭空强制一场军事入侵。对应的地区任务仍要求真实的出资、交付、审查与改约。

## 六 制作验收要求

- 新开局所有候选国家都具备正确的保护资格和内部战争能力。
- 分别验证大元及另一外部强国的普通宣战、特殊理由、事件宣战、参战召集、附庸战争和继承战争入口。
- 检查皇帝更替、国家改名、政体变化、退出会盟、会盟瓦解、释放国家和提前统一后的保护传承。
- 在第五、第五十、第一百和第一百二十年检查保护状态，确保没有到期解除。
- 检查内战、反吞并、反集权、共同防卫和任务演练能正常进行。
- 保护资格不向界外国家或跨域领土无限扩展；贸易、知识和非军事外交能持续提供经营内容。
- 后续若单独策划开放世界模式，使用明确的模式选择和边界；默认版本的隔离不由事件、时间或误操作自动取消。
