# 特色兵精锐定位调整（0.3.1）

日期：2026-10-15。以本地提交 `451376f` 为数值基线。目标是让九种特色兵在各自用途上进入原版强势特色兵的属性区间。

对照使用当前安装游戏的前两个时代定义，包括纳瓦拉弩手、早期派克步兵、外乡勇士、瓦兰吉卫队、伊比利亚轻骑、草原弓骑、改革外乡勇士、战车营与图阿雷格骑兵。原版常见的专精幅度包括伤害修正约20%、防护修正5%—10%、主动性+2至+3、侧翼+0.20至+0.30。以同类、同等兵力和适用场景衡量，编制差异单独保留。

## 保留的经营约束

- 九种兵均为每队500人；两种进阶兵仍小于原版第二时代普通重步兵的1000人编制。
- 每月净增一队特色兵增加2点役负。未净增时不重复收取，既有阈值、恢复和供养机制继续适用。
- 维护与建造配方、供粮消耗、招募地区、机构、科技、役负及共享军额条件保持原值。
- 不新增全军增益，不改动原版单位定义。

## 验证

已核对九种兵完整继承链、500人编制、配方、供粮与补给，以及招募条件。每种兵至少改善一项最终基础属性，没有属性或地形修正退步。保留每队2点净增役负。
