# 神圣巴蜀帝国诸侯层级与可选国家策划

开局采用七个帝国圈、三十六个府州诸侯组和一百六十四个单地块独立诸侯国。七个地区负责组织共同事务，每个地块国家都可以单独选择游玩；府州组提供更细的地方合作、身份与事件变体。

数量来自当前安装地图的可拥有地块候选清单。地图范围暂沿用川东、川南和川西的候选省份，排除不可拥有山脉及东川、乌撒、乌蒙三个边缘省份，再按玩法重组为七圈。它是架空巴蜀范围，包含重庆和部分边地，边界可在制作前调整。当前国家名称和身份为策划候选，具体政体、旗帜与开局数值后续制作。

完整名单见[诸侯候选表](data/prince_roster_draft.csv)，其中保留原版地块键、原版名称、拟用国名、身份、文化、宗教和产物。部分常用地名作拟名校订，原版字段保留便于核对。

## 一 三层结构

**神圣巴蜀帝国 → 七个帝国圈 → 三十六个府州诸侯组 → 一百六十四个可选诸侯国。**

帝国圈与府州组是合作和政治层级，不额外生成七个大国或三十六个宗主国。圈内国家保持独立，仍可内部结盟、竞争、继承、兼并与参选。开局逐地块建国，之后数量随局势变化。

| 层级 | 主要职能 | 玩家如何参与 |
| --- | --- | --- |
| 帝国 | 皇帝选举、共同法令、锅气、跨圈事务、自治盟约 | 普通诸侯有议会票；皇帝受履约和预算约束 |
| 帝国圈 | 共用地区科技、圈级项目、防务分摊、长期章程 | 通过贡献、轮值与委托争取圈级主持 |
| 府州诸侯组 | 本地水权、关卡、市场、山门与地方纠纷 | 小国先主持近邻事业，再把成果带入圈级政治 |
| 诸侯国 | 本国经营、义气、军队、外交与科技投入 | 一块地也能走完整地区任务线 |

七大选侯是帝国授予国家的特殊席位，七个帝国圈是地理合作体系，两者分别运行。圈主持不自动取得选侯票；选侯被吞并后仍按原有补位规则处理。

府州组由参与国轮值或选择一个有能力的协调者。协调者主持当前事务，不拥有其他成员的领土和军队。诸侯组代表可以在圈会上提出议题，帝国最终表决仍保留国家参与权。

## 四 小国身份与选国体验

诸侯的身份提供起步任务、政治诉求和本地特权。同圈国家共享研究传统，身份可以改变任务的实践版本。山门国家可以承担施济、接待和采购，关隘国家可用后勤履约，商邦可用合同参与，地方领主邦可组织公共工程。

| 身份 | 起步选择 | 长期政治诉求 |
| --- | --- | --- |
| 地方领主邦 | 修路、维护、结盟或发展本地经营 | 维护自治、争取主持和地位 |
| 盐业商邦 | 井灶维护、作坊合同 | 融资权、供额分摊和债务承认 |
| 江运或茶市商邦 | 运输、接驳、市场订单 | 通行稳定、费率与经营权 |
| 山门领 | 施济、接待、知识交流 | 地方地位、中立信用和治理边界 |
| 关隘边侯 | 守备、后勤、联络 | 费用来源、驻防权限和轮值责任 |
| 地方自治社 | 共同仓储、代表议约、互助 | 公开分摊、代表参与和地方保障 |

候选表的身份只是初始建议。正式开局应让领主邦、商邦、山门与地方自治机构在地图上交错出现，保留各地文化和宗教。人口、收入、军队与发展条件须逐国验证，以保证所有候选国家真正可选且有起步行动。

### 三个选国例子

- 成都组内可选成都、郫县、双流、新都、金堂五国。成都承担皇都会务；其他国家可以靠水利、供给或课题成为合作方，也能争取帝位。
- 叙州组内可选宜宾、富顺、南溪、庆符、宣化五国。盐井、宴席和采购角色依当地条件选择，组内分账会影响整个盐酒圈的政策。
- 重庆组内可选巴县、巴南、璧山、綦江、江津、南川六国。山城主持、转运、陆路接驳与防务形成不同入口。

## 五 与百年内容的衔接

前期从本组合作起步；中期争取圈级委托和跨圈伙伴；晚期处理组内兼并、代表交班和旧合同；满百年后参与圈章程与帝国宪章。

府州组的地理记录保留，国家数与协调者随局势变化。某组统一为一个国家后，内部事务改为地方机构和利益主体之间的治理；圈级和跨圈合作继续运行。地区终点的国家级待遇沿原科技规则处理。

外部强国的军事隔离按[自治盟约与区域隔离](regional_isolation.md)执行。巴蜀内部的诸侯竞争、圈级合作和百年治理构成主要战役内容。
