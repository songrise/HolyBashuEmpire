# 神圣巴蜀帝国 v0.01 诸侯层级

**神圣巴蜀帝国 → 七个帝国圈 → 三十六个可选府州诸侯国。**

三十六个原地图府州分组各建一国，共保留一百六十四个可拥有地块；每国拥有 3–10 个地块。旧逐地块建国方案不再用于本版开局。七圈负责地区身份与协作，不另造七个领土宗主国。

本版以一个帝国国际组织及七个圈级国际组织表达合作关系。诸侯同时属于帝国和自己的圈；八个组织使用原生国际组织界面，专用层级界面留待后续。

每圈开局一名选侯，共七席。成都开局主持帝国；空缺按原生特殊身份自动补位，本版后续补位不强制每圈一席。

“天府之国”对合资格诸侯的域内地块提供粮食产出 +10%、本地建造速度 +10%；按固定地域维护，每个地块一份。域外所有者不享有该待遇。
