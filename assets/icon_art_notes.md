# 图标资源说明

使用内置 image_gen 生成。科技图标按用户要求采用精灵图方法：公共科技和七圈分别生成一张 4 列 2 行图集，按行优先顺序对应各组八个研究节点。共 64 个独立图标；资源和局势为另行生成的 11 个单图。

风格以 EU5 原版器物图标为参考：克制的手绘笔触、陈旧木材与青铜、纸张与布料、左上方光源、透明底。图集提示词及节点映射完整保存在 icon_generation.json。锅气的最早提示词为恢复后的描述，其余条目保留实际提交文本。

build_icon_assets.py 只执行格子裁切、透明边界裁定、等比缩放和 DDS 格式导出，不重新绘制源图。科技导出为 256×256，资源和局势为 128×128；源 PNG 留在 assets 中。发行包不需要本机字体，旗帜字体仅在重新生成时使用。
