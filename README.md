# 神圣巴蜀帝国

Europa Universalis V 架空喜剧风味包。四川各个可拥有地块在开局成为独立诸侯国，玩家通过结盟、经营、选举与战争，在一个热衷开会和吃席的帝国里争夺地位。

风味方向由用户确定：神罗与巴蜀梗的架空喜剧。
