# 神圣巴蜀帝国

Europa Universalis V 架空喜剧风味包。四川各个可拥有地块在开局成为独立诸侯国，玩家通过结盟、经营、选举与战争，在一个热衷开会和吃席的帝国里争夺地位。

当前地图草案为七个帝国圈、三十六个府州诸侯组、一百六十四个开局独立可选国家。默认模式以自治与通商盟约维持区域隔离，圈外强国不能主动宣战；内部战争、政治和商业竞争保留。

帝国地域内所有本地诸侯共有常驻「天府之国」修正：粮食产出 +10%、本地建造速度 +10%。地域与资格固定，兼并和统一后保留且不重复叠加。

风味方向由用户确定：神罗与巴蜀梗的架空喜剧。
