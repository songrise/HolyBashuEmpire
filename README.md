# 神圣巴蜀帝国 v0.1.1

独立 EU5 模组，使用原生 `.metadata/metadata.json`，可单独加载并作为创意工坊上传目录。当前结构是**神圣巴蜀帝国 → 七个帝国圈 → 三十六个可选府州诸侯国**，共同统治一百六十四个地块。当前安装版日志报告 EU5 1.4.0，元数据匹配 1.4.*。

## 安装与开局

1. 解压发行包，保留 `holy_bashu_empire`、`Install-Mod.ps1` 与 `Launch-Mod.ps1` 的相对位置。
2. 运行 `Install-Mod.ps1`，在 EU5 模组管理器中启用“神圣巴蜀帝国 Holy Bashu Empire”。也可以直接运行 `Launch-Mod.ps1` 加载本包；脚本默认使用独立的 `文档/Paradox Interactive/EU5 Holy Bashu Empire` 用户目录及专属播放集，存档也放在这里。脚本支持自定义游戏目录和用户数据目录。
3. 新建 **1337 年**游戏，在巴蜀地图上选择府州诸侯，或从新增推荐国家中选择。请使用新存档。
4. 在原版科技树研究本圈特色课题；通过“决议”查看会盟账本、续办公共事业与完成阶段验收。皇帝另有“召开帝国茶会”。选侯在巴蜀国际组织的选举界面投票。

已有同名安装由安装脚本移至用户目录下的 `hbe-mod-backups` 时间戳备份目录。安装脚本不会修改 Steam 游戏文件。其他修改 1337 年领土开局的模组会与本包的所有权文件产生冲突，首轮测试请单独启用本包。

## 本版内容

- 36 国开局，每国 3–10 个地块；36 位架空统治者，36 面原生纹章旗帜，配放大的隶书两字简称。
- 巴蜀帝国与七圈共八个独立国际组织。欧洲神罗保留；七圈在本版用圈级协作组织表达，尚未制作专用层级界面。
- 七席选侯开局每圈一席，严格多数决定帝位；席位空缺由原生状态自动补位，本版补位允许其他存活成员。
- “天府之国”：域内粮食产出 +10%、本地建造速度 +10%，每块地一份，永久维持。
- 域外宣战和参战召集的隔离规则；内部诸侯战争及本地叛乱保留。
- 64 项原版特色科技：8 项共同知识、7 圈各 8 项；每圈两项基础与两条互斥专精。新研究使用原版队列与研究成本，保留年代门槛；旧计时研究兼容结算。
- 35 项地区阶段验收任务，按 1337、1352、1372、1397、1437 年推进；7 类三年交付、五年续办事业与地区履约储备。
- 川南盐引贷款、债务上限、年度利息与还款；锅气、义气及帝国茶会的资源取舍。
- 96 个事件：原有 17 个加新增 79 个，含 36 国专属、21 个地区事件、局势结算和百年章程议决。循环经营在 1457 年后继续。
- 全部 96 个事件正文扩写为巴蜀历史叙事，去掉神罗笑梗，融入都江堰、蜀锦、卓筒井、蜀道、钓鱼城与雅州茶马贸易等背景。账本事件保留动态数值摘录。
- 43 个机制概念与 12 个历史概念接入原生悬停指南：事件、决议和局势内的着色术语可直接查看用途、获取方式、时间门槛与关联规则。史料出处见 `docs/player_guide_v01.md`。
- 原生局势“巴蜀大开席”：1337 年 10 月 1 日启动，全部帝国成员参加；三年一届分账，共锅、分锅、账房三种立场，两类跨圈工程、实际合同交付、争席危机，以及 1437 年以后七圈表决百年章程。
- 64 个独立科技图标，由 ImageGen 生成 8 张 4×2 精灵图后拆分；10 个特色点数图标和 1 个局势图标。科技入口为原版科技树，图标只用于科技节点。

64项特色科技接入原版科技树，每国显示8项公共课题及所属圈8项地区课题；A/B支线仍互斥。新研究使用原版研究队列与研究成本，不再收取旧决议的固定金币和年限。原有变量解锁每月同步，首次完成奖励只结算一次。旧存档已完成课题自动转换为原版科技，尚在进行的课题按旧计时完成。70项地方事业、阶段验收、议事和局势行动保留决议入口；原版任务树及后续政治、社会、建筑、兵种扩展另见策划。

## 原版内容入口与文本

70项决议登记具体国家标签并使用`country_specific_decisions`；36个国家专属一次性事件登记DHE索引，独立月概率为0，继续由原有脉冲派发。总事件数仍为96；其他60个共享、计时或循环事件继续通过局势、决议和原有脉冲呈现，不强改为一次性历史事件。64个科技使用原版advances数据库与具体标签潜力条件。国家特色入口读取这些原版内容，未实装的兵种、建筑和改革不会虚报数量。36国分别提供`country_history_TAG`背景介绍及独立开局描述类别。决议补齐`.title`、`.title.entry`与`.desc.entry`，正文包含完整风味叙述，办理规则另列。

## 美术

96 个事件按题材共用 12 幅新绘插画，使用柔和色块、可见笔触与简化细节的 EU5 协调风格。帝国和七圈各有专属组织徽标，八张组织面板按帝国议事堂或地区场景配图。局势“大开席”使用专用大厅大图，朱红、金色和旗帜适度提高饱和度。

70 个非科技决议各有独立配图，由七张 5×2 透明精灵图拆分，覆盖阶段验收、公共事业、贷款、议事和局势行动；配图按原版弹窗540:220比例导出，主体等比例居中。64个科技器物图仅用于原版科技树，不进入决议弹窗。10 个特色点数图标与局势小图标保留。

事件场景接入原生插画数据库，并保留原生人物层、照明与镜头；不打包原版插画。旗帜引用游戏原生纹章构件，由游戏渲染布面，简称保留隶书，改用白底黑字旗签，发行包只含自制遮罩与旗签。当前美术占位剩余工坊封面 `.metadata/thumbnail.png`。

源图、节点顺序、映射与实际提示词见 `assets/icon_generation.json` 和 `assets/full_art_generation.json`；裁切、缩放与 DDS 导出由 `tools/build_icon_assets.py` 和 `tools/build_full_art_assets.py` 完成。

## 创意工坊

上传目录选择 `holy_bashu_empire` 本身，其下第一层必须包含 `.metadata`、`loading_screen`、`main_menu` 与 `in_game`。在游戏的模组工具中选择本地模组并填写工坊介绍、标签和封面，再上传。元数据的 `id` 留空，首次发布后由工具管理工坊标识。本包尚未上传工坊。
